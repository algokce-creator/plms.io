# PLMS - Professional Life Management System

Multi-agent AI sistem avukatlar, doktorlar, mimarlar, danışmanlar için.

## 🎯 Nedir?

Mahkeme tutanakları, ses kayıtları, belgeler otomatik analiz eden AI asistanı.

- ✅ Halüsinasyon-free (sadece gerçek veriler)
- ✅ Otomatik uyarılar (tarih kaçırma yok)
- ✅ KVKK uyumlu (veriler güvenli)
- ✅ Platform-agnostik (Web, Mobile, Desktop)

## 🏗️ Tech Stack

- **Frontend:** Next.js 14 + React + Tailwind
- **Backend:** Express.js + Node.js + TypeScript
- **Database:** PostgreSQL (Supabase)
- **AI:** Claude 3.5 Sonnet + RAG + Whisper
- **Deploy:** Vercel + Render.com

## 🚀 Kurulum

```bash
pnpm install
pnpm dev
```

## 📍 Development Servers

- **Web:** http://localhost:3000
- **API:** http://localhost:4000
- **Database Studio:** http://localhost:5555
